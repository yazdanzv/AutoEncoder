## Code guide

`HW3.ipynb` is the executable analysis. Its cells load and preprocess the data, train an autoencoder for dimensionality reduction, inspect clusters in the encoded space, and train an MLP classifier. `HW3_Report.pdf` records the written analysis. Open the notebook in Jupyter and run cells in order with the libraries imported by the notebook installed. The committed `env/` directory is an old environment snapshot; create a fresh environment for new work instead of relying on it.
